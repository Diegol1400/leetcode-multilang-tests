# LeetCode Multi-Language Solutions with Tests

This repository contains **LeetCode problem solutions implemented in C, C++, and Python**, with a strong focus on **clean code, correctness, and automated testing**.

The main goal of this project is to reinforce **data structures, algorithms, and problem‑solving skills**, while following **good software engineering practices** such as unit testing, clear structure, and readable code.

---

## Features

* Solutions written in **C, C++, and Python**
* Unit tests for each problem

  * **Google Test** for C/C++
  * **pytest / unittest** for Python
